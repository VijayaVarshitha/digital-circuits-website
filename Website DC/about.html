About Boolean Logic Solver

Boolean Logic Solver is a digital logic tool designed to make Boolean logic problems easier to understand and solve.

What can it do?

The solver provides tools for:

  • Truth Tables
  • Minterms / Maxterms
  • Boolean Expressions
  • Karnaugh Maps
  • Boolean simplification
  • Logic Circuit Diagrams
  • NAND-only and NOR-only implementations
  • Verification of results
